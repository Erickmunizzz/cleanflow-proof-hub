# Cleanflow Proof Hub

Analise o projeto CleanFlow UK existente antes de modificar qualquer código.

Objetivo: transformar o protótipo atual em um micro-SaaS de gestão operacional e comprovação de serviços para pequenas empresas de limpeza comercial no Reino Unido.

REGRAS:

Preserve o design existente, as cores, os componentes e a identidade visual. deixe toda a escrita em ingles .

Não reconstrua o aplicativo do zero.

Não altere funcionalidades que já funcionam sem necessidade.

Não adicione novas bibliotecas sem justificar.

Não implemente pagamentos, salários, contabilidade ou novas integrações.

Não modifique o banco de dados nesta etapa.

Reutilize componentes existentes sempre que possível.

PRIMEIRO, apenas analise o código e entregue:

Estrutura atual de páginas e rotas.

Componentes reutilizáveis.

Dados fictícios e estados locais que precisam ser substituídos.

Funcionalidades que estão apenas simuladas.

Diferenças entre o fluxo do administrador e o do funcionário.

Proposta de arquitetura com perfis admin, supervisor e cleaner.

Lista de arquivos que precisariam ser alterados.

 Mantenha todos os componentes visuais em Tailwind CSS e React já configurados (botões, cards, tabelas e modais)."

Comportamento Mobile vs Desktop: Adicione: "Respeite a responsividade: o fluxo do Cleaner deve permanecer otimizado para telas de smartphone e o fluxo do Admin para desktop."
